# Pruebas con Postman

Importa `CotizaPro Backend.postman_collection.json`.

Orden recomendado:

1. `Health`
2. `Auth - Register`
3. `Auth - Login`
4. `Me`
5. `Empresa - Actualizar`
6. `Clientes - Crear`
7. `Cotizaciones - Crear`
8. `Cotizaciones - PDF`

El login guarda automaticamente `token`.

La creacion de cliente guarda automaticamente `cliente_id`.

La creacion de cotizacion guarda automaticamente `cotizacion_id`.
